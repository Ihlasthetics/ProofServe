# Recipes

Owned by Tugrahan. Recipe artifacts are reviewable configuration sources; they
do not prove that a Gateway is configured or that a Recipe has been run.

## Available Recipe

- [ProofServe Verified Paid Service](bazantic-verified-paid-service.md) — exact
  Bazantic prompt, ProofServe and Hedera Mirror Node tool contracts, strict
  input and discriminated output schemas, bounded polling, unchanged receipt
  evidence, positive-recipient-transfer confirmation, arbitrary-precision budget
  comparison, and exactly-once/no-retry rules.

Live configuration and acceptance evidence are tracked in
[`docs/bazantic-evidence.md`](../docs/bazantic-evidence.md) and remain subject to
separate authorization.
